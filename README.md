# CORALES — Página web

Sitio informativo del proyecto audiovisual **CORALES · La belleza fuera de lugar**.

## Cómo verla

```bash
cd "/Users/oscarvaldes/Documents/pagina web"
python3 -m http.server 8000
```

Abre [http://localhost:8000](http://localhost:8000)

O abre `index.html` con doble clic.

## Estructura

1. Intro → botones a Video y Proceso
2. Concepto
3. Investigación
4. Proceso
   - Moodboards, Guion, Thumbnails, Cronograma/Escaleta,
     Storyboard, Bits/Color script, Style frames,
     Personaje, Pruebas animadas
5. Video final
6. Créditos

## Archivos
